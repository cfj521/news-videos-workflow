# 新闻视频自动化工作流 — 总实现计划

> **For agentic workers:** 按编号顺序执行各子计划，每个计划产出可独立测试的软件。

**Goal:** 从零搭建新闻视频自动化全链路系统（6 个 Pipeline Stage + Web 面板）

**Architecture:** Python (FastAPI + Celery) 后端，React (Vite + TypeScript) 前端，SQLite 数据库，Redis 消息队列。Provider 抽象层解耦所有外部服务。MVP 使用 Hyperframes 渲染视频。

**Tech Stack:** Python 3.12+, FastAPI, Celery, SQLAlchemy, Alembic, feedparser, Scrapling, httpx, edge-tts, Hyperframes (Node.js), React, Vite, TypeScript, Tailwind CSS

                    ──→ Plan 4 (Video Pipeline)

                    ──→ Plan 6 (Frontend)
