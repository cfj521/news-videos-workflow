# ---- 系统级前置依赖（非 pip，pip 装不了，需另行安装；下面仅备忘）----
#   Ubuntu/Debian:  sudo apt install -y ffmpeg fonts-noto-cjk
#     - ffmpeg        : 视频合成必需（也是 Hyperframes 路兜底器）
#     - fonts-noto-cjk: 标题烧录用的中日韩字体（FFmpeg 路 drawtext 需要；缺失仅跳过烧录）
#                       Windows 用系统自带 C:/Windows/Fonts/msyh.ttc，无需安装
#   Hyperframes 视频路（video_route=hyperframes 时）:  Node >= 22 + hyperframes
#     - 装 Node 22 (Ubuntu，默认源版本过旧用 NodeSource):
#         curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash - && sudo apt install -y nodejs
#     - 再装 hyperframes:  sudo npm i -g hyperframes
#     - 不装也行：首次渲染由 npx 联网拉取；缺失则自动回退 FFmpeg 合成
